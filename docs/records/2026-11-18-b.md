## 任务 C · 耦合增强(完成,commit 036cef5)

### 1. 协同回滚
仅当所有参与者 `supports_state_capture() == true` 时启用:每网格点对所有人
`begin_rollback_point`,任一 Discard → 逆拓扑序全员 `rollback`,整网步长
减半重试(上限 5 次,下限 `min_retry_step`),成功后按拓扑序
`commit_rollback_point`;有一个不支持 → 退回现有各自 `step` 语义。

### 2. Integer/Boolean 信号连接
`CsInstance` trait 新增可选方法
`read_integer`/`write_integer`/`read_boolean`/`write_boolean`(默认实现抛
Config"不支持");FMI 2 映射现有整型/布尔绑定,FMI 3 映射现有
int32/boolean 绑定;`Coupling.signal~ : SignalType = Real`(
`SignalType { Real; Integer; Boolean }`) 可选命名参数。

### 3. 代数环定点求解(Jacobi)
`CoupledConfig.max_loop_iterations~ : Int? = None`(None=保持现状:环即拒绝)
与 `loop_tolerance~ : Double = 1e-9`;环内成员(Kahn 失败后未放置者)按
当前快照写输入 → 全员步进 → 刷新观测,分量绝对差 vs `loop_tolerance`
收敛或达上限抛 Config(含迭代数与残差);t0 不求解环,直接用 FMU
初始输出。

## 任务 D · ME 自适应步长求解器 RKF45(完成,commit 0c58d84)

- `MeConfig` 新增 `adaptive~ : Bool = false`、`tolerance~ : Double =
  1e-6`、`max_step~ : Double? = None`;adaptive=false 时与从前逐位一致。
- Fehlberg 4(5) 嵌入对:误差范数
  `|y5-y4| <= tolerance * (|nominal| + |y5|)`,nominals 保护 x≈0;通过则
  接受(按误差 ×1.5–2 放大,受 max_step 上限),不通过则减半(下限
  `step_size*1e-6`,再小报错),NaN/Inf 直接报错。

  `completed_integrator_step`/`enter_event_mode` 流程。
- 记录:`times` 记录实际接受步时刻(不规则网格),`steps` 计接受步数,
  末步截断到 stop_time。
- 测试:指数模型误差≤容差且导数求值次数远少于同精度固定步 RK4;
  VanDerPol adaptive 43 步 vs 细步 RK4 5000 步,t=5 处误差~1.8e-6/4.7e-7;
  BouncingBall 事件次数正确、不穿地。

## Linux CI 修复(commit c2db657 → 9451766,Run 44334787140 全绿)

第一轮推送后 Linux CI 连续失败(Run 14–20,Windows 从 Run 16 起全绿),逐一
定位并修复了 6 个问题:

1. **--timeout 单位错误**(c2db657):`@env.now()` 返回毫秒(moonbitlang/core/
   env 源码确认 "in milliseconds since the Unix epoch"),原代码把秒数直接加到
   毫秒时间戳上,10 秒超时只有 10 毫秒余量,CI 机器上解析 FMU 超过 10ms 即在
   t=0 触发 Timeout。第一次修复误按纳秒乘了 1e9(10 秒变 115 天),最终修正为
   `seconds.to_uint64() * 1_000UL`(秒→毫秒)。
2. **WASM 测试的 Windows 专属路径**(9c3ec2c):`%USERPROFILE%/.moonfmi/bin/
   wit-bindgen.exe` 在 Linux 上是字面量,删除,仅保留 PATH 探测,缺失时 SKIP。
3. **ensure_test_dir 绝对路径 bug**(532d250 + 9451766):Linux 绝对路径
   `/home/runner/...` 被分割为相对段,从 CWD 创建 `./home/runner/...` 而非
   `/home/runner/...`,FMU 夹具目录从未真正创建,`write_bytes_to_file` 报
   "No such file or directory" 后 SIGABRT。修复:路径以 `/` 开头时根前缀为
   `/`,且根前缀拼接段时保留前导斜杠(第一次修复把 `/home` 错拼成 `home`,
   第二次修正)。
4. **starts_with 已弃用**(be176bf):`--deny-warn` 下弃用警告即错误,改用
   `has_prefix`。
5. **1MB XML 解析 release 栈溢出**(1d6dd84):`read_events()` 一次性构建
   11000+ 事件的数组,release 模式下 0xc0000409;改为 `read_event()` 流式循环。
6. **moon fmt 漂移**(351bece):`moon fmt --check` 在 CI 门禁中失败。

最终 Run 44334787140(commit 9451766):`check (ubuntu-latest)` 与
`check (windows-latest)` 均 **success**——本轮所有功能(E/B/A/C/D 五个任务)
在两个平台全部通过 CI 质量门禁。
