# 实施记录

本目录保存按日期归档的工作日志，记录每天实际做了什么、如何验证。

与相邻目录的分工：

- [`../roadmap/`](../roadmap/README.md)：接下来要做什么，阶段、任务、验收标准；
- [`../design/`](../design/README.md)：为什么这样设计，架构、接口、取舍；
- `records/`：已经做了什么，命令、结果、遗留问题。

记录是历史快照，不随设计变更回改。

## 2. 命名约定

```text
YYYY-MM-DD.md
```

文件名只写日期，不加阶段、周次或其他后缀。同一天的内容合并在一份日志里。
