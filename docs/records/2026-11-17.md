## P6 · 源码 FMU 导出(E-01…E-08)

- **模型 IR**(`src/export/ir.mbt`):版本无关的 `ModelIr` + 受限显式方程
  (`der(x)=f`、`y=g`),复用 schema 的 Causality/Variability/Initial。
  自检 EX-001..017(未知引用、非法组合、按版本拒绝数组、call 白名单)。
  值引用 = 声明序;GUID/instantiationToken 由 IR 内容 sha256 派生。
- **XML 生成**(`xml.mbt`):FMI 2/3 双版本,元素顺序按 XSD;
  合成 `der(x)` 局部变量(FMI 2 `<Real derivative>`、FMI 3
  `derivative` 属性),ModelStructure 指向合成变量(MD-041/046);
  InitialUnknowns 升序合并;单位(BaseUnit/DisplayUnit)、FMI 3
  `Dimension` 数组;effective initial 与 `derive_initial` 一致。
  FMI 2 导出拒绝数组/宽类型(EX-020)。
- **C 代码生成**(`codegen/fmi2_entry/fmi3_entry.mbt`):
  - `moonfmi_model.h/.c`:结构体 + reset/derivatives/outputs;
  - FMI 2/FMI 3 入口:生命周期状态机、值引用 switch、get 时惰性重算
    输出、数组 offset/required-count 两段式(FMI 3)、`der(x)` 惰性求导、
    set 仅参数/输入;未声明能力的符号**不导出**(否则 MoonFMI shim 的
    符号存在性检查会误判能力,这是测试抓出来的真 bug);
  - FMI 3 event mode:`hasEventMode=true` + eventModeUsed 分支(与
    MoonFMI loader 的无条件 eventModeUsed=true 实例化对齐)。
- **布局/打包**:sources/ + CMakeLists.txt + buildDescription.xml(FMI 3)
  + documentation;确定性 ZIP(与 B-05 同管线)→ sha256 稳定。
- **集成测试**(`tests/integration/export_fmu_wbtest.mbt`,6 个):
  导出 → clang 编译 → 打包 → `load_fmi2_fmu`/`load_fmi3_fmu` →
  `run_cs_simulation`/`run_me_simulation`:
  - FMI 2 CS:与 (1-k·h)^n 逐点 1e-12 一致;
  - FMI 2 ME:RK4 与 e^{-1} 差 ≤1e-5;
  - FMI 3 CS:同闭式解一致;
  - FMI 3 数组 passthrough:u[3] 写读 roundtrip(真实 ABI);
  - 确定性:两次导出 sha256 相同;
  - 单元测试另 5 个(XML 双版本、GUID、EX-010、单位、FMI 2 数组拒绝)。
- **schema 公共构造器**:`BaseUnit::of`、`UnitDef::simple`(导出侧无法
  构造非 pub(all) 结构,补充官方入口)。

  `fmi2Serialize/DeSerializeFMUstate` 与非标准的

  的缓冲,通用增长策略必须先走尺寸查询。
